Experiment protocol & limits

Each model trains on the 60,000-image training split. Evaluation uses a fixed random subset of the separate 10,000-image test split. Labels are used only in captions. The paired run uses one training seed, so these results cannot establish a statistically reliable winner. Lower noise-prediction MSE alone does not establish better sample quality.

Linear β is scaled from the original 1,000-step DDPM budget. Cosine uses the offset 0.008 schedule with β capped at 0.999. Sampling uses all trained timesteps, a fixed posterior variance, and clipped clean estimates.
